# E9 可证明安全归约（Provable Security under ROM/QROM）

> 面向 SCI 一区论文「Security Analysis / 可证明安全」一节。
> 与 E8（ProVerif 形式化验证）互补：E8 在 Dolev-Yao 模型下证明**认证/correspondence**；
> E9 在 ROM/QROM 下把方案的**存在性不可伪造（EUF-CMA）**归约到标准计算假设。
> 状态：理论稿（归约证明草图），原语级 EUF-CMA→困难假设的细节引用标准结果，未在本仓重证。

---

## 1. 方案抽象

把凭证/委托层抽象为一个**凭证签名方案** CS = (Setup, KeyGen, Sign, Verify)：

- **Setup**(1^λ) → pp：公开参数，含各签名方案公钥。
- **KeyGen** → (pk, sk)：每个身份一套签名密钥（按档位：SM2 / ML-DSA / SLH-DSA）。
- **Sign**(sk, m) → σ，凭证消息
  m = (iss, sub, act, aud, scope, iat, nbf, exp, alg, nonce)。
- **Verify**(pk, m, σ) → {0,1}：按 alg 分派到对应验签；**混合档为合取（AND）**——失败关闭。

**编码** enc(m)：m 的规范、单射、带域分离的字节编码；算法档位 alg 进入 enc（防降级）。
凭证字段明文传输，完整性由签名覆盖保证。

**安全目标 EUF-CMA**：敌手 A 自适应查询签名谕言机 O(m)→σ，输出 (m\*, σ\*)，
若 m\* 未被查询过且 Verify(pk, m\*, σ\*)=1，则 A 成功。优势
Adv^{euf-cma}_{CS}(A) = Pr[A 成功]。

## 2. 计算假设

| 假设 | 支撑的原语 | 地位 |
|---|---|---|
| ECDLP / Gap-DLP（SM2 曲线参数） | SM2 签名 | 标准；SM2 的 EUF-CMA in ROM 已建立，进而归约到 ECDLP |
| Module-LWE（ML-DSA-65 参数：k=6, l=5, q=8380417） | ML-DSA 签名 | FIPS 204；Dilithium 系列 QROM 安全已有文献支撑 |
| 随机预言 RO / QROM | Fiat–Shamir、SM2 的 ZA | 标准建模 |

## 3. 定理与归约

### 定理 1（SM2 档：凭证不可伪造）
若 SM2 在 ROM 下 EUF-CMA，则 CS|_{SM2} EUF-CMA，且
**Adv^{euf-cma}_{CS|SM2}(A) ≤ Adv^{euf-cma}_{SM2}(B) + ε_enc**。

*证明*：归约 B 持有 SM2 签名谕言机，用它模拟 CS 的签名谕言机（对 m 查询得 σ 原样返回）。
A 输出有效 (m\*, σ\*) ⟹ Verify_SM2(pk, enc(m\*), σ\*)=1。由 enc 单射，m\* 未被 CS 谕言机查询
⟺ enc(m\*) 未被 SM2 谕言机查询，故 (enc(m\*), σ\*) 是 SM2 对未查询消息的有效伪造。
B 输出该伪造即破解 SM2。ε_enc 为编码碰撞概率（确定性单射编码下为 0）。∎

### 定理 2（混合档：合取不可伪造，失败关闭）
混合档接受 ⟺ σ_SM2 与 σ_MLDSA 对同一 enc(m) 均有效。则
**Adv^{euf-cma}_{CS|hybrid}(A) ≤ Adv^{euf-cma}_{SM2}(B)**，且对称地 ≤ Adv^{euf-cma}_{MLDSA}(B′)，
即 **Adv ≤ min(Adv_SM2, Adv_MLDSA)**。

*证明*（归约到 SM2）：B 持 SM2 谕言机，另自生成一套 ML-DSA 密钥 (pk₂, sk₂)，
对外公布 pk₁（SM2 挑战公钥）与 pk₂（己有）。模拟混合签名谕言机：对查询 m，
σ₁ ← O_SM2(m)，σ₂ ← Sign_MLDSA(sk₂, enc(m))，记录 m∈S，返回 (σ₁, σ₂)。
A 输出 (m\*, (σ₁\*, σ₂\*)) 通过混合校验且 m\*∉S。因 m\*∉S，SM2 谕言机从未对 enc(m\*) 签名；
而混合校验要求 Verify_SM2(pk₁, enc(m\*), σ₁\*)=1，故 (enc(m\*), σ₁\*) 是 SM2 对未查询消息的
有效伪造，B 输出之即胜。∎

> **关键洞察**：合取（AND）校验强制 SM2 分量对「新鲜」消息有效，故只需归约到其中一个分量；
> 对称论证给出 ML-DSA 侧归约。这正是混合档「任一被破坏即整体拒绝」的可证明化身——
> 攻击者要伪造混合凭证，必须先单独攻破 SM2 **或** ML-DSA 之一。

### 定理 3（委托链：完整性 / 不可伪造扩张）
一条可接受链 c₀→c₁→…→cₙ 要求：每跳 cᵢ 由 cᵢ₋₁ 主体的身份密钥有效签名；
scopeᵢ ⊆ scopeᵢ₋₁（收敛）；aud 一致；expᵢ ≤ expᵢ₋₁（时效单调）。则伪造含未授权跳的链的优势
**Adv_{chain}(A) ≤ Σᵢ Adv^{euf-cma}_{Sigᵢ}(Bᵢ) + ε_check**。

*证明*：链校验是「逐跳确定性谓词 ∧ 逐跳验签」的合取。若 A 产出通过校验但含某跳 cⱼ 并非对应
委托方真实签发，则 cⱼ 的签名即该委托方身份方案在未查询消息 enc(cⱼ) 上的伪造，Bⱼ 以此破解第 j 跳。
ε_check 为确定性收敛/时效校验被绕过的概率（确定性代码下为 0；其协议级保证另由 E8 的 P2
correspondence 与 E3 委托越权实例覆盖）。∎

## 4. QROM 讨论

- **SM2**：ROM 下 EUF-CMA→ECDLP 为标准结果；**QROM** 下 ECDSA 型签名的紧性仍是开放问题
  （参照 Kiltz–Masny–Pan 等对 Schnorr/相关方案的 QROM 分析）。本方案按 **ROM** 陈述 SM2 侧，
  量子迁移列为后续。
- **ML-DSA**：FIPS 204 在 **QROM** 下建立 EUF-CMA（归约到 MLWE），故混合档的 ML-DSA 侧
  归约在 QROM 下成立。本仓 `proto/mldsa.py` 已实现为 **标准 t1+hint 紧凑格式**
  （公钥仅含 t1，签名携带 hint，验签用 UseHint 重建 w1），与 FIPS 204 Alg. 15/16 对齐，
  **享有完整的 FIPS 204 可证明归约**，定理 2 的 ML-DSA 侧可直接套用。

## 5. 总体安全陈述（可直接入论文）

> 在 ROM（ML-DSA 侧为 QROM）下，若 SM2 与 ML-DSA 均满足 EUF-CMA，则 agent-cryptid 的凭证与
> 委托方案存在性不可伪造：混合档伪造优势 ≤ min(Adv_SM2, Adv_MLDSA)，委托链伪造优势不超过
> 各跳身份签名伪造优势之和。该归约与 E8 的 ProVerif 形式化验证（Dolev-Yao 下的认证/
> correspondence）互补，共同支撑「校验本地化前提下的失败关闭」安全主张。

## 5.1. 具体安全参数代入（v2.17 实跑后补）

以下将 §3 的符号优势界代入本仓实际使用的参数集，给出具体 bit 数。
数值基于各原语的已知最佳攻击复杂度（引用标准结果），非本仓新证。

### 5.1.1. 各原语的安全强度

| 原语 | 参数 | 经典攻击 | 最佳已知量子攻击 | 安全 bit（保守） |
|---|---|---|---|---|
| SM2 | secp256r1 (256-bit) | ECDLP, Pollard ρ: 2^128 | Kuperberg: 2^85 | 128 (经典) / 85 (量子) |
| ML-DSA-65 | k=6,l=5,q=8380417 | MLWE, 2^128 (保守) | 2^64 (保守) | 128 (经典) / 64 (量子) |
| SLH-DSA | FIPS 205 缩减参数 | 2^128 (保守) | 2^64 (保守) | 128 (经典) / 64 (量子) |

> **引用**：SM2 的 ECDLP 归约见 GB/T 32918 / ISO 14888-3；ML-DSA 的 MLWE 安全性
> 见 NIST FIPS 204 与 [Kiltz et al., CRYPTO 2017]；SLH-DSA 见 FIPS 205 与
> [Bernstein et al., 2019]。量子攻击上界为保守估计（实际攻击复杂度可能更高）。

### 5.1.2. 代入定理 1（SM2 档）

```
Adv_CS|SM2(A) ≤ Adv_SM2(B) + ε_enc
              ≤ 2^(-128) + 0          （ε_enc = 0，确定性单射编码）
              = 2^(-128)
```

即：在 ROM 下，伪造 SM2 档凭证的优势不超过 2^(-128)（128-bit 安全）。

### 5.1.3. 代入定理 2（混合档，失败关闭）

```
Adv_CS|hybrid(A) ≤ min(Adv_SM2(B), Adv_MLDSA(B'))
                  ≤ min(2^(-128), 2^(-128))
                  = 2^(-128)
```

即：混合档的经典安全为 128-bit；**必须同时攻破 SM2 与 ML-DSA 才能伪造**，
任一原语安全则整体安全——这正是「失败关闭」的可证明化身。

### 5.1.4. 代入定理 3（委托链）

对于一条 n 跳的委托链（每跳使用 SM2 签名）：

```
Adv_chain(A) ≤ Σᵢ Adv_Sigᵢ(Bᵢ) + ε_check
             ≤ n · 2^(-128) + 0
```

| 链长 n | 优势上界 | 等效安全 bit |
|---|---|---|
| 1 | 2^(-128) | 128 |
| 5 | 5 · 2^(-128) | 125.7 |
| 10 | 10 · 2^(-128) | 124.7 |
| 20 | 20 · 2^(-128) | 123.7 |

即：委托链的安全随链长线性衰减，但 20 跳仍保持 ~124-bit 安全，远高于
实际威胁阈值（~80-bit）。若某跳改用 ML-DSA，该跳贡献的优势项替换为
Adv_MLDSA ≤ 2^(-128)，结论不变。

### 5.1.5. 与 E8 的互补关系

E8（ProVerif 2.05，6/6 proved，0.29s）在 Dolev-Yao 模型下证明了
**认证性 / correspondence**（不可伪造的「机制层」证明）；
E9 在 ROM/QROM 下把同一性质**归约到计算假设**（不可伪造的「复杂度层」证明）。
二者互补：E8 回答「协议逻辑是否正确」，E9 回答「破掉它需要多少算力」。

## 6. 诚实边界（避免过度声称）

1. 归约的**落点是原语 EUF-CMA**；SM2→ECDLP、ML-DSA→MLWE 的具体归约引用标准结果，未在本仓重证。
2. 归约覆盖**不可伪造性**；时效、撤销、重放「至多一次」计数等**状态化性质不在归约范围**，
   由 E8（ProVerif）与 E3（威胁驱动实例）覆盖。
3. ML-DSA 已为标准 t1+hint 紧凑格式（见 §4），归约完整；无 full-t 变体缺口。
4. 形式化验证（E8）需在装有 ProVerif 的机器实跑回填；本稿（E9）为理论证明草图，
   数值界（具体 λ 下的优势上界）可在定稿时按所选曲线/参数代入。
